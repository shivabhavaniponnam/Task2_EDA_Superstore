📊 Task 2 – Exploratory Data Analysis & Dashboard (Superstore Dataset)

🔷 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Sample Superstore dataset to understand sales performance, profit trends, and business insights. The analysis is done using Python, and a dashboard is created using Power BI for visualization.

🛠️ Tools & Technologies

* Python (Pandas, Matplotlib, Seaborn)
* Power BI
* SQL

📁 Project Structure

* **data/** → Dataset files
* **code/** → Python scripts for EDA
* **outputs/** → Graphs and results
* **dashboard/** → Power BI dashboard file
* **eda_insights.txt** → Key findings
* **sql_queries.txt** → Business queries

📊 Key Analysis Performed

* Data cleaning and preprocessing
* Handling missing values
* Outlier detection
* Sales and profit analysis
* Region-wise and category-wise insights
* Data visualization using charts

📈 Dashboard Features

* Total Sales and Total Profit KPIs
* Sales by Category
* Profit by Region
* Monthly Sales Trends
* Interactive filters for better analysis

🔍 Key Insights

* Technology category has the highest sales
* West region generates maximum profit
* Discounts reduce overall profit
* High sales do not always mean high profit

🎯 Conclusion

This project helps in understanding business performance using data analysis and visualization. It provides meaningful insights that can help in better decision-making.
